# 상식 퀴즈 게임

한국사, 세계지리, 과학, 예술과 문화 4개 분야의 4지선다 상식 퀴즈 게임. 별도 서버나 빌드 도구 없이 `index.html`을 브라우저에서 열면 바로 실행된다.

- **기본 퀴즈**: 문제 풀이, 즉시 피드백(정답/오답 표시와 해설), 결과 화면, 난이도별 점수
- **확장 기능**: 보너스·콤보 점수 시스템, 게임 모드 3종(전체 도전 / 카테고리별 / 스피드), 힌트, 타이머, 모드별 최고 기록
- **자동화**: 문제 데이터를 점검하고 추가하는 프로젝트 전용 슬래시 명령어 3개

## Folder Structure

```
03-quiz-game/
├── README.md
├── CLAUDE.md          ← 프로젝트 노트, 문제 작성 기준
├── PRD.md             ← 요구사항 문서
├── PROMPTS.md         ← 단계별 구현 프롬프트
├── index.html         ← 빈 컨테이너(<main id="app">), 화면은 JS가 그린다
├── styles.css         ← 카드 레이아웃, 보기 버튼, 피드백 팝업, 타이머 등
├── quiz-data.js       ← 문제 데이터 (QUIZ_CATEGORIES, QUIZ_DATA)
├── quiz-game.js       ← 게임 로직 (QuizGame 클래스, ScoreManager)
└── .claude/
    └── commands/
        ├── quiz-validate.md   ← /quiz-validate [카테고리]
        ├── quiz-range.md      ← /quiz-range [시작 번호] [끝 번호]
        └── quiz-add.md        ← /quiz-add [카테고리] [난이도]
```

## How to Run

`index.html`을 더블클릭해서 기본 브라우저로 연다. 별도 설치나 서버 실행이 필요 없고 인터넷 연결도 필요 없다.

## Game Flow

1. **모드 선택 화면**: 전체 도전 / 카테고리별 / 스피드 퀴즈 중 선택 (카테고리별은 카테고리를 한 번 더 고른다). 각 모드 옆에 지금까지의 최고 점수가 표시된다.
2. **문제 화면**
   - 상단: 진행도(예: 3 / 41), 현재 점수, 타이머, 연속 정답 수(🔥)
   - 카테고리와 난이도 배지, 문제, 4개의 보기, 힌트 버튼
3. **피드백 팝업**: 보기를 고르면 정답은 초록, 선택한 오답은 빨강으로 표시되고 팝업이 뜬다.
   - 정답: 해설과 획득 점수 내역(기본 점수, 시간 보너스, 힌트 미사용 보너스, 연속 정답 보너스)
   - 오답: 정답 보기와 해설
   - 마지막 문제에서는 버튼이 "결과 보기"로 바뀐다.
4. **결과 화면**: 최종 점수, 정답 개수, 정답률, 카테고리별 정답 수, 최대 연속 정답, 최고 기록 갱신 여부. "다시 시작"을 누르면 모드 선택 화면으로 돌아간다.

## Game Modes

| 모드 | 문제 구성 | 비고 |
|---|---|---|
| 전체 도전 | 모든 카테고리의 전체 문제 | 한국사 → 세계지리 → 과학 → 예술과 문화 순서, 카테고리 안에서는 쉬움 → 보통 → 어려움 순서 |
| 카테고리별 | 선택한 카테고리의 문제만 | 카테고리마다 최고 기록을 따로 저장 |
| 스피드 퀴즈 | 전체 문제 중 무작위 20문제 | 문제당 15초 제한, 남은 시간이 5초 이하이면 타이머가 빨간색, 시간이 지나면 오답 처리 |

## Score System

점수 계산은 `ScoreManager.calculate()`가 담당한다.

| 항목 | 점수 |
|---|---|
| 기본 점수 | 쉬움 10 (×1) / 보통 15 (×1.5) / 어려움 20 (×2) |
| 시간 보너스 | 문제가 표시된 뒤 10초 미만에 정답 → +3 |
| 힌트 미사용 보너스 | 힌트를 쓰지 않고 정답 → +2 |
| 연속 정답 콤보 | 3연속 +2 / 5연속 +5 / 10연속 +10 (해당 연속 횟수에 도달한 문제에서 1회) |
| 힌트 사용 | -2 (버튼을 누른 즉시 차감, 점수는 0 아래로 내려가지 않음) |

- 보너스는 정답일 때만 붙는다. 오답과 시간 초과는 0점이고 연속 정답 수가 0으로 초기화된다.
- 한 문제에서 얻을 수 있는 기본 + 보너스 최대치는 어려움 20 + 3 + 2 = 25점(콤보 제외)이다.
- 최고 기록은 `localStorage`의 `quiz-best-scores` 키에 모드별로 저장된다(`all`, `speed`, `category:<카테고리명>`).

**힌트**: 문제당 1회 사용할 수 있다. 오답 보기 2개가 흐려지고(선택 불가) 문제별 힌트 문구가 표시된다.

## Question Data

`quiz-data.js`에 들어 있다.

| 카테고리 | 문제 수 | 난이도 구성 (쉬움 / 보통 / 어려움) |
|---|---|---|
| 한국사 | 11 | 4 / 5 / 2 |
| 세계지리 | 10 | 4 / 4 / 2 |
| 과학 | 10 | 4 / 4 / 2 |
| 예술과 문화 | 10 | 4 / 4 / 2 |
| 합계 | 41 | 16 / 17 / 8 |

문제 하나의 구조:

```js
{
    id: 12,
    category: "세계지리",
    difficulty: "easy",             // "easy" | "medium" | "hard"
    question: "세계에서 가장 긴 강은? (전통적 측정 기준)",
    options: ["아마존강", "나일강", "양쯔강", "미시시피강"],
    answer: 1,                      // options 배열에서 정답의 위치 (0~3)
    explanation: "나일강은 약 6,650km로 ...",
    hint: "아프리카 북동부를 흐르며 ..."
}
```

- 보기는 실행 중에 섞지 않는다. 그래서 정답 위치(0~3번)가 한쪽에 몰리지 않도록 데이터에서 고르게 배치한다.
- `id`는 겹치지 않는 번호이고, 새 문제는 현재 가장 큰 `id`에 1을 더해 추가한다.

## Question Guidelines

문제를 만들거나 추가할 때 `CLAUDE.md`에 적어 둔 기준을 따른다.

1. **정답이 하나뿐인가?** — 다르게 해석될 여지가 있으면 조건을 문제에 적는다.
2. **최상급 표현에 기준이 있는가?** — "가장 큰", "최초의" 같은 표현에는 측정 기준을 적는다. 예) "면적을 기준으로 가장 큰 대륙", "내부 장기 중 가장 큰 것", "세계에서 가장 긴 강은? (전통적 측정 기준)"
3. **시간과 범위가 명확한가?** — 변할 수 있는 정보는 시점을 적고, 지리적·분류적 범위를 한정한다.
4. **교차 검증했는가?** — 불확실한 정보는 둘 이상의 출처로 확인하고, 논란이 있는 내용은 주류 학설을 기준으로 하거나 출제하지 않는다.

## Custom Slash Commands

`.claude/commands/`의 마크다운 파일이 이 프로젝트에서만 쓰는 슬래시 명령어가 된다. 이 폴더에서 Claude Code를 실행하고 `/`를 입력하면 `(project)` 표시와 함께 나타난다. 명령어 파일을 새로 만들거나 고쳤다면 Claude Code를 다시 시작해야 반영된다.

| 명령어 | 인수 | 하는 일 |
|---|---|---|
| `/quiz-validate` | `$ARGUMENTS` — 카테고리 (생략하면 전체) | 문제에서 '가장', '최초', '최대' 같은 모호한 최상급 표현을 찾아 어떤 기준을 적어야 하는지 알려 준다 |
| `/quiz-range 1 20` | `$1` 시작 번호, `$2` 끝 번호 | 범위 안 문제의 난이도 분포와 정답 위치 분포를 분석하고 치우침이 있으면 알려 준다 |
| `/quiz-add 한국사 medium` | `$1` 카테고리, `$2` 난이도 | 기준에 맞는 새 문제를 `quiz-data.js`에 추가하고 문제 수와 정답 분포 변화를 알려 준다 |

- `$ARGUMENTS`는 명령어 뒤에 입력한 값 전체, `$1`, `$2`는 공백으로 구분된 첫 번째·두 번째 값으로 바뀐다.
- 현재 41번 문제(병인양요 때 약탈된 외규장각 의궤)는 `/quiz-add 한국사 medium`으로 추가한 문제다.
- 홈 디렉터리의 `~/.claude/commands/`에 두면 모든 프로젝트에서 쓰는 전역 명령어가 된다.
