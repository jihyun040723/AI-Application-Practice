# Claude Code 구현 프롬프트 (3단계 중 1·2단계)

PRD를 바탕으로 정리한 Claude Code 구현 프롬프트. 한 번에 만들지 않고 단계별로 나누어 진행한다.

## 1단계: 핵심 퀴즈 시스템 구축

목표: 기본적인 퀴즈 플레이가 가능한 MVP(Minimum Viable Product) 구현

1. 프로젝트 초기 설정
   - 프로젝트 구조 설정 (Vanilla JS)
   - 기본 HTML/CSS 레이아웃 구성
   - 상태 관리 구조 설계
2. 문제 데이터 구조 및 관리
   - 4개 카테고리 × 10문제 = 총 40문제
   - 난이도별 점수 시스템 (쉬움: 10점, 보통: 15점, 어려움: 20점)
   - 카테고리: 한국사, 세계지리, 과학, 예술과 문화
3. 게임 진행 로직
   - `QuizGame` 클래스로 상태 관리
   - 정답/오답 판정과 즉시 피드백
   - 게임 완료 시 결과 표시

결과물: `index.html`, `styles.css`, `quiz-data.js`, `quiz-game.js`

## 2단계: 게임 확장 - 점수 시스템과 게임 모드

목표: 게임을 더욱 흥미롭게 만들기 위한 점수 시스템과 다양한 게임 모드 추가

1. 점수 시스템 (`ScoreManager`)
   - 기본 점수 + 난이도별 배수 (easy: 1x, medium: 1.5x, hard: 2x)
   - 시간 보너스: 10초 미만 답변 시 +3점
   - 힌트 미사용 보너스: +2점
   - 연속 정답 콤보 보너스: 3연속 +2, 5연속 +5, 10연속 +10
2. 게임 모드
   - 전체 도전: 모든 카테고리 전체 문제
   - 카테고리별: 선택한 카테고리 문제
   - 스피드 퀴즈: 20문제, 문제당 15초 제한
3. 화면 요소: 남은 시간 타이머, [힌트 사용 (-2점)] 버튼, 연속 정답 표시, 정답 팝업의 점수 내역
