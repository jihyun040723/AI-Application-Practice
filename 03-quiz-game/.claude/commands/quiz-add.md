새 퀴즈를 추가하는 작업을 해 줘.
$1은 카테고리, $2는 난이도(easy, medium, hard)로 받아서 처리해.

1. quiz-data.js를 읽고 기존 문제와 같은 형식으로 문제를 하나 만들어 줘.
   (id, category, difficulty, question, options 4개, answer, explanation, hint)
   - id는 현재 가장 큰 id + 1
   - 이미 있는 문제와 중복되지 않게 할 것
2. CLAUDE.md의 "퀴즈 문제 교차 검증 가이드라인"을 꼭 지켜 줘.
   - 정답이 하나뿐일 것
   - '가장', '최초' 같은 최상급 표현을 쓰면 측정 기준을 문제에 명시
   - 변할 수 있는 정보는 쓰지 말고, 연도·인물처럼 확정된 사실만 사용
   - 확실하지 않은 사실은 출제하지 말고 나에게 알려 줄 것
3. 정답 위치가 한쪽에 치우치지 않도록 해당 카테고리의 현재 정답 분포를 확인하고,
   가장 적게 쓰인 번호에 정답을 배치해 줘.
4. quiz-data.js의 해당 카테고리 구역 끝에 추가한 뒤, 다음을 보고해 줘.
   - 추가된 문제 내용과 정답
   - 전체 문제 수와 해당 카테고리 문제 수의 변화
   - 정답 분포 변화
