quiz-data.js의 퀴즈 문제를 검증해 줘.

사용자가 카테고리를 지정하면 해당 카테고리의 문제만 검증하고,
지정하지 않으면 전체 문제를 검증해 줘.
$ARGUMENTS에 입력된 값을 카테고리로 사용하면 돼.

검증할 때는 '가장', '최초', '최대', '최고', '최소' 같은 모호한 표현이 있는지 찾아서
어떤 기준을 명시해야 하는지 알려 줘.

각 문제마다 CLAUDE.md의 "퀴즈 문제 교차 검증 가이드라인"을 기준으로 다음을 확인해 줘.
1. 정답이 하나뿐인가? (다른 해석이 가능하면 조건 명시)
2. 최상급 표현에 측정 기준이 있는가?
3. 시간과 범위가 명확한가?
4. 의심스러운 사실은 없는가?

결과는 다음 형식으로 정리해 줘.
- 발견된 문제: 문제 ID, 카테고리, 난이도, 문제 문장, 모호한 표현, 필요한 기준
- 수정이 필요한 문제는 수정안을 제안하고, 내가 승인하면 quiz-data.js에 반영
- 마지막에 검증한 문제 수, 최상급 표현이 사용된 문제 수, 기준이 명확한 문제 수, 개선이 필요한 문제 수를 요약
