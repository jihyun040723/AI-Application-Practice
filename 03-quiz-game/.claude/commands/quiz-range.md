quiz-data.js에서 $1번부터 $2번까지의 문제를 검토하는 기능을 만들어 줘.
문제의 난이도와 정답 분포를 확인하게 해 줘.

각 문제에 대해 다음을 보여 줘.
1. 문제 번호, 카테고리, 난이도
2. 문제 내용

그리고 지정한 범위 전체에 대해 다음을 분석해 줘.
- 난이도별 개수와 비율 (쉬움/보통/어려움)
- 정답 위치 분포: 정답이 0번, 1번, 2번, 3번 선택지에 각각 몇 개인지 (한 곳에 치우쳐 있으면 경고)
- 같은 정답 번호가 연속 3번 이상 나오는 구간이 있는지
- 너무 쉽거나 너무 어려운 문제가 특정 구간에 몰려 있지는 않은지

치우침이 있으면 균형을 맞추기 위한 권장 사항을 제안해 줘.
(데이터는 수정하지 말고 분석 결과만 보여 줘.)
