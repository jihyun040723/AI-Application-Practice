# My Tasks (할 일 관리 앱)

순수 HTML/CSS/JavaScript로 만든 개인용 할 일 관리 웹 앱. 별도 서버나 빌드 도구 없이 `index.html`을 브라우저에서 열면 바로 실행된다. 모바일 중심의 카드형 화면(루트)과, 같은 기능을 PC 화면에 맞게 다시 디자인한 사이드바형 화면(`web_version/`) 두 가지로 구성되어 있다.

## Folder Structure

```
02-todo-list/
├── README.md
├── CLAUDE.md
├── index.html                  ← 앱 구조 (HTML)
├── style.css                   ← 스타일 (라이트/다크 테마, 모달)
├── script.js                   ← 전체 로직 (TaskManager 클래스, 자동 분류)
├── 화면캡처.png                 ← 카드형 화면 캡처 (PC 디자인 작업용 참고 이미지)
├── todo-app-conversation.txt   ← 작업 기록
└── web_version/                ← PC 화면용 사이드바 버전
    ├── README.md
    ├── index.html
    ├── style.css
    └── script.js
```

## How to Run

- 카드형 화면: `index.html`을 더블클릭해서 기본 브라우저로 연다.
- PC 사이드바 화면: `web_version/index.html`을 더블클릭해서 연다.

별도 설치나 서버 실행이 필요 없다. 두 화면은 같은 `localStorage` 키를 사용하므로 같은 브라우저에서 열면 할 일 목록과 설정이 공유된다.

## Features

**할 일 관리**
- 할 일 추가 (Enter 키 또는 추가 버튼), 최대 100자
- 체크박스로 완료/미완료 토글, 완료 시 취소선
- 항목 더블클릭으로 텍스트·카테고리·마감일·반복 주기 인라인 수정 (Enter 저장, Esc 취소)
- X 버튼으로 개별 삭제, "완료된 항목 모두 삭제" (확인창 포함)
- 드래그 앤 드롭으로 순서 변경

**카테고리**
- 업무(파란색) / 개인(초록색) / 공부(보라색) 3종
- 추가 시 드롭다운으로 선택, 항목에 색상 배지로 표시
- 필터 버튼(전체/업무/개인/공부)으로 카테고리별 보기, 각 버튼에 개수 표시

**진행률 대시보드**
- 전체 진행률 "N/M 완료 (%)" + 프로그레스 바
- 카테고리별 미니 진행률
- 오늘 추가된 할 일 개수
- 오늘의 격언 표시

**검색/정렬**
- 실시간 검색 필터
- 정렬: 최신순 / 오래된순 / 카테고리순 / 완료 상태순 / 마감일순 (선택한 정렬 방식은 저장됨)

**마감일 지정**
- 할 일 추가·수정 시 마감일(날짜) 지정 가능
- 마감일이 지났고 미완료인 항목은 빨간 배지로 강조 표시
- "마감일순" 정렬 옵션 (마감일 없는 항목은 뒤로 정렬)

**반복 할 일**
- 할 일 추가·수정 시 반복 주기(없음/매일/매주) 지정 가능
- 반복 할 일을 완료 처리하면 다음 주기의 할 일이 자동으로 새로 생성됨 (마감일이 있으면 그 날짜 기준, 없으면 오늘 기준)
- 반복 설정된 항목은 🔁 아이콘으로 표시

**다크 모드**
- 토글 스위치 (단축키 `Alt+D`)
- 배경 `#1A1A1A`, 카드 `#2D2D2D`, 텍스트 `#E0E0E0`
- 선택한 테마는 localStorage에 저장되어 다음 방문에도 유지

**데이터 백업**
- "내보내기" — 현재 할 일 목록을 JSON 파일로 다운로드
- "가져오기" — JSON 파일 업로드로 복원 (덮어쓰기 전 현재 데이터가 `my-tasks-data-backup-<시각>` 키로 자동 백업)
- 모든 데이터는 `localStorage`에 저장되어 새로고침해도 유지됨

**키보드 단축키**
- `Alt+N`: 할 일 입력창 포커스
- `Alt+D`: 다크/라이트 모드 전환
- `Alt+1/2/3/4`: 전체/업무/개인/공부 필터 전환
- `Ctrl+/`: 검색창 포커스 (`web_version`)

## Auto Categorization

할 일 텍스트에 들어 있는 키워드를 분석해서 어울리는 카테고리를 추천하는 기능.

**동작 방식**
1. 카테고리별 키워드 목록과 텍스트를 비교해 일치하는 키워드마다 점수를 더한다.
2. 가장 점수가 높은 카테고리를 후보로 정하고, 신뢰도를 `후보 카테고리 점수 ÷ 전체 점수`로 계산한다.
3. 후보가 현재 선택한 카테고리와 다르고 신뢰도가 임계값(기본 60%) 이상일 때만 추천한다.
4. 일치하는 키워드가 없거나 두 카테고리의 점수가 같으면 추천하지 않는다.

한 글자 키워드(집, 책, 팀)는 다른 단어 속에 우연히 들어가기 쉬워서 점수를 0.5로 줄이고, 단어의 맨 앞에서 시작할 때만 일치로 본다.

**카드형 화면 (루트)**
- 추가 버튼을 누르면 추천 모달이 뜬다. 예) 카테고리 "업무" 상태에서 "영화 보러 가기" 입력 → `"개인" 카테고리로 분류하는 것을 추천합니다. 신뢰도: 100%`
- **확인**: 추천 카테고리로 추가 / **취소**, `Esc`, 바깥 영역 클릭: 선택해 둔 카테고리로 추가

**PC 화면 (`web_version`)**
- 입력하는 동안 입력창 아래에 `"업무" 카테고리로 분류하시겠습니까?` 막대가 나타난다. **적용**은 카테고리 선택값을 추천으로 바꾸고, **무시**는 그대로 둔다.

**[🏷 자동 재분류]**
- 이미 등록된 할 일 전체를 다시 분석해 임계값 이상으로 다른 카테고리가 추천되는 항목을 찾는다.
- 변경 대상 목록(최대 8개 표시)을 보여 주고, 확인하면 한꺼번에 카테고리를 바꾼다.

**[⚙ 분류 설정]**
| 항목 | 설명 | 기본값 |
|---|---|---|
| 자동 분류 기능 활성화 | 끄면 추천과 재분류를 하지 않는다 | 켜짐 |
| 분류 제안 표시 | 끄면 확인 없이 추천 카테고리로 바로 분류하고 알림만 띄운다 | 켜짐 |
| 신뢰도 임계값 | 30%~100% (5% 단위). 높을수록 확실한 경우에만 추천 | 60% |
| 키워드 미리보기 | 카테고리별 키워드 일부를 보여 준다 | - |

설정은 `localStorage`에 저장된다.

**키워드 목록** (`script.js`의 `CATEGORY_KEYWORDS`)

| 카테고리 | 키워드 |
|---|---|
| 업무 | 회의, 미팅, 프로젝트, 보고서, 클라이언트, 개발, 코딩, 시스템, 업무, 출장, 기획, 발표, 메일, 계약, 견적, 거래처, 결재, 야근, 회사, 스케줄, 팀, 납품, 배포, 고객 |
| 개인 | 집, 가족, 친구, 취미, 여행, 쇼핑, 운동, 요리, 병원, 영화, 청소, 빨래, 장보기, 약속, 생일, 산책, 데이트, 카페, 휴가, 미용실, 헬스, 주말 |
| 공부 | 공부, 학습, 강의, 시험, 과제, 책, 프로그래밍, 자격증, 수업, 복습, 예습, 논문, 암기, 독서, 단어, 문제집, 퀴즈 |

키워드를 추가하려면 `CATEGORY_KEYWORDS`의 해당 배열에 단어를 넣으면 된다.

## Desktop Version (web_version)

모바일 화면에 맞춰 가운데 카드 한 장으로 구성했던 화면을 PC의 넓은 화면에 맞게 다시 디자인한 버전. 이전 화면을 그대로 두기 위해 별도의 `web_version/` 폴더에 저장했다. 기능은 루트와 같고 화면 구성만 다르다.

| 항목 | 카드형 (루트) | 사이드바형 (`web_version`) |
|---|---|---|
| 레이아웃 | 가운데 600px 카드 | 좌측 280px 고정 사이드바 + 넓은 메인 영역(최대 980px) |
| 카테고리 필터 | 상단 알약 버튼 | 사이드바 목록 (색 점 + 항목 수) |
| 진행률 | 상단 대시보드 박스 | 사이드바 (전체 + 카테고리별 막대 + 오늘 추가 수) |
| 데이터 관리 | 버튼 줄 | 사이드바 버튼 (내보내기 / 가져오기 / 자동 재분류 / 분류 설정 / 완료 항목 삭제) |
| 단축키 안내 | 없음 | 사이드바 하단 단축키 표 |
| 추가 영역 | 목록 위 한 줄 | 흰색 입력 패널 (카테고리, 내용, 마감일, 반복) |
| 목록 제목 | 없음 | "전체/업무/개인/공부 할 일" + 표시 중인 개수 |
| 카테고리 추천 | 확인 모달 | 입력창 아래 인라인 막대 (적용 / 무시) |

- 창 너비가 820px 이하이면 사이드바가 위쪽으로 접혀서 한 열 레이아웃으로 바뀐다.
- 사이드바 상단 스위치 또는 `Alt+D`로 다크 모드를 켠다.

## Data Structure

```json
{
  "tasks": [
    {
      "id": "1758540000000abc123",
      "text": "프로젝트 기획서 검토",
      "category": "work",
      "completed": false,
      "createdAt": "2026-09-22T05:25:59.497Z",
      "order": 0,
      "dueDate": "2026-09-25",
      "repeat": "none"
    }
  ],
  "settings": {
    "currentFilter": "all",
    "currentSort": "date-desc",
    "isDarkMode": false,
    "autoCategory": {
      "enabled": true,
      "showSuggestions": true,
      "threshold": 0.6
    }
  }
}
```

- 저장 키: `my-tasks-data` (두 화면 공통)
- `category`: `work` / `personal` / `study`
- `repeat`: `none` / `daily` / `weekly`
- `autoCategory`가 없는 예전 데이터를 불러오면 기본값으로 채워진다.

## Possible Additional Features

- 우선순위(높음/보통/낮음) 설정
- 사용자가 직접 키워드를 추가/삭제하는 편집 화면
