[2] 챕터 06 - 프로젝트 개선과 작업 관리
  - 화면캡처.png: 모바일 중심 현재 화면을 캡처해 Study-02 폴더에 저장
  - 프롬프트: "[Image #1] 현재 디자인은 모바일에 최적화되어 있는 것 같아. 데스크톱 환경에서도
              전체 화면에서 UI를 볼 수 있도록 디자인을 수정해 줘. 수정한 디자인은 'web_version'이라는
              새로운 폴더를 생성한 뒤, 그곳에 저장해 줘."
  - 결과: web_version/ (index.html, style.css, script.js) - 좌측 사이드바 + 메인 영역
  - 확인: "내일 회사 스케줄 확인" 입력 → "업무" 카테고리 추천 막대 표시
  - @script.js : 다크 모드 관련 함수 분석 (toggleTheme / applyTheme / body.dark)
  - @web_version : 폴더 전체를 분석해 데스크톱 환경 최적화 여부 확인
  - /config(설정 확인), /doctor(시스템 진단), /export(대화 내보내기)
