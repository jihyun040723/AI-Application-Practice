# My Tasks - 데스크톱(PC) 버전

상위 폴더(`02-todo-list/`)의 카드형 할 일 앱을 PC 전체 화면에 맞는 사이드바 레이아웃으로 다시 디자인한 버전. 상위 폴더의 파일은 그대로 두고 이 폴더에 따로 저장했다. 기능은 상위 폴더의 앱과 동일하다.

## Table of Contents

- [How to Run](#how-to-run)

## Folder Structure

```
web_version/
├── README.md
├── index.html    ← 사이드바 + 메인 영역 구조
├── style.css     ← 데스크톱 레이아웃, 라이트/다크 테마, 모달
└── script.js     ← TaskManager 클래스 (상위 폴더와 같은 로직 + 인라인 추천, 목록 제목)
```

## How to Run

`index.html`을 더블클릭해서 기본 브라우저로 연다. 데이터는 상위 폴더 앱과 같은 `localStorage` 키(`my-tasks-data`)에 저장되므로 같은 브라우저에서는 두 화면이 같은 할 일 목록을 보여 준다.

## Layout

화면은 좌측 사이드바와 우측 메인 영역 두 칸으로 나뉜다.

**사이드바 (280px, 화면에 고정)**
- 상단: 앱 이름, 다크 모드 스위치
- 카테고리: 전체 / 업무 / 개인 / 공부 (카테고리 색 점, 항목 수 표시, 선택한 항목 강조)
- 진행률: 전체 진행률 막대, 카테고리별 진행 막대, 오늘 추가한 개수
- 데이터 관리: 내보내기, 가져오기, 자동 재분류, 분류 설정, 완료 항목 삭제
- 단축키 안내

**메인 영역 (최대 980px, 가운데 정렬)**
- 오늘의 격언 배너
- 검색창 + 정렬 선택
- 할 일 입력 패널: 카테고리 선택, 내용 입력, 추가 버튼, 마감일, 반복 주기
- 목록 제목("전체 할 일", "업무 할 일" 등)과 표시 중인 항목 수
- 할 일 목록 (카테고리 색 막대, 배지, 마감일, 반복 아이콘, 경과 시간, 삭제 버튼)

창 너비가 820px 이하이면 사이드바가 위로 접히고 한 열로 표시된다.

## Features

- 할 일 추가 / 완료 체크 / 삭제 / 더블클릭 인라인 수정 / 드래그 앤 드롭 순서 변경
- 카테고리(업무·개인·공부) 필터, 실시간 검색, 정렬(최신순·오래된순·카테고리순·완료 상태순·마감일순)
- 마감일 지정(지난 항목은 빨간 배지), 반복 할 일(매일·매주, 완료하면 다음 항목 자동 생성)
- JSON 내보내기 / 가져오기 (가져오기 전 현재 데이터 자동 백업)
- 다크 모드 (선택 상태 저장)

**자동 카테고리 추천 (인라인)**
- 할 일을 입력하는 동안 키워드를 분석해, 선택한 카테고리와 다른 카테고리가 확실하면 입력창 아래에 막대를 보여 준다.
  - 예) 카테고리가 "개인"인 상태에서 "내일 회사 스케줄 확인" 입력 → `"업무" 카테고리로 분류하시겠습니까? (신뢰도 100%)`
- **적용**: 카테고리 선택값을 추천으로 바꾼다. **무시**: 선택한 카테고리를 그대로 유지하고, 입력창을 비우기 전까지 같은 막대를 다시 띄우지 않는다.
- 분류 설정에서 "분류 제안 표시"를 끄면 막대 없이 추천 카테고리로 자동 분류하고 알림만 표시한다.
- **자동 재분류**: 등록된 할 일 전체를 다시 분석해 카테고리를 한꺼번에 변경 (변경 목록 확인 후 적용)
- **분류 설정**: 기능 켜기/끄기, 제안 표시 켜기/끄기, 신뢰도 임계값(30~100%, 기본 60%), 키워드 미리보기

## Keyboard Shortcuts

| 키 | 동작 |
|---|---|
| `Alt+N` | 할 일 입력창 포커스 |
| `Ctrl+/` | 검색창 포커스 |
| `Alt+D` | 다크/라이트 모드 전환 |
| `Alt+1` ~ `Alt+4` | 전체 / 업무 / 개인 / 공부 필터 전환 |
| `Enter` | 입력창에서 할 일 추가 |
